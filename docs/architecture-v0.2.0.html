pdf-to-epub v0.2.0 总体架构

单一引擎 × 双接口（CLI / GUI）× 双模式（批量智能·默认 / 主动审阅）

双模式（同一引擎）

  • • 批量智能（默认）：全程零干预，不一致决策由 Scout 增强仲裁接管
  • • 兜底哲学：do-no-harm —— 宁可不改，不可改错；全部留痕于报告
  • • 主动审阅：检查点全开（profile / 标题地图 / needs_review）
  • • needs_human 旗标决定何时值得打开审阅模式，而非运气

可插拔 Scout 大脑

  • • 本地（默认 · 离线）：qwen2.5vl + qwen3
  • • 外部 API（可配置）：更强视觉模型，仅 Phase 0 联网，其余仍全本地
  • • 假设 → 多实例验证 → 通过才写入：小模型立法的安全刹车
  • • 零硬编码：本书专属规则运行时发现，写进 book_profile.json，用完即弃

v0.2.0 变更清单

  • • 新增：Phase 0 Scout / Phase 2 结构重建 / 最简 GUI / 封装后自动质检
  • • 沿用：MinerU standard 解析 + 三级校验漏斗（v0.1.0 已验证）
  • • 退化保证：侦察一无所获 → 退回 MinerU 原生标题，不劣于 v0.1.0
  • • 待实测：Phase 0 最小原型（本地小模型能否自发现「页眉=篇名」类规律）
